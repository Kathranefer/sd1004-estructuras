# sd1004-estructuras
La estructura que más me costó fue la lista enlazada, porque al principio me resultaba difícil entender cómo cada elemento podía estar conectado con el siguiente. Al representarla mediante flechas pude comprender mejor cómo funciona. 
Pinterest- Árbol
Pienso que Pinterest puede organizar su contenido como un árbol, porque tiene diferentes categorías y dentro de ellas hay otras más específicas. Por ejemplo, de una categoría como decoración pueden salir ideas para habitaciones, jardines, salas, etc.
Facebook- Grafo
Creo que Facebook se parece a un grafo porque toda la información está conectada. Por ejemplo, una persona tiene amigos, pertenece a grupos, hace publicaciones, recibe comentarios y reacciones, y todo eso se relaciona entre sí.
YouTube-Árbol + lista enlazada
Creo que YouTube puede utilizar algo parecido a un árbol para organizar los videos por categorías, como música, videojuegos o educación. También pienso que los videos se pueden relacionar entre sí mediante enlaces, especialmente cuando aparecen recomendaciones de videos similares.
